# Cargar tablas Staging PSQL #

La ruta del dataset se pasa con `-v datadir=<ruta absoluta a Data/dataset>`.
Es una ruta del **servidor** de PostgreSQL, porque `COPY` se ejecuta de ese lado.

## Windows

```powershell
& "C:\Program Files\PostgreSQL\18\bin\psql.exe" -U postgres -d penguin_academy_db `
  -v datadir=C:/Users/kento/OneDrive/Desktop/Database_Introduction/Data/dataset `
  -f 2_data_loading.sql
```

## Linux / macOS

```bash
psql -U postgres -d penguin_academy_db \
  -v datadir="$(pwd)/../Data/dataset" \
  -f 2_data_loading.sql
```

Si falta la variable, el script corta con un mensaje explicando el uso en lugar de fallar con un error de sintaxis.

## Si PostgreSQL corre en otra máquina o en un contenedor

`COPY` necesita que la ruta exista en el servidor y que el rol tenga permiso para leer archivos (superusuario o `pg_read_server_files`). Cuando eso no se cumple, hay que reemplazar cada `COPY ... FROM 'ruta'` por `\copy ... FROM 'ruta'`, que lee del lado del cliente y no requiere privilegios especiales.
